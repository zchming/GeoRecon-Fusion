# 阶段5子步骤：最简场景级选择与回退

只实施整场景候选选择；不修改相机、世界坐标系或点文件，不混合不同方法视图，不过滤点、不加权、不联合优化。沿用stage3的scan1/dev、scan6/test及四条件。既有测试结果在阶段3/4已公开，因此这是固定样本上的回顾性验证，不声称新的未见盲测。

## 先核对阶段4

逐一检查8份诊断与已发布副本相同、观测/残差NPZ摘要匹配、预测指纹一致；24条诊断为10条证据完整、8条部分可用、6条未知。保留模糊COLMAP低残差却位姿错误、spaced3仅一条边有证据、OOM/no model未知的反例。不能用跨方法最小Sampson或未经校准confidence直接选优。

## 固定的规则家族与开发集拟合

只比较三方法全部6种**固定优先级排列**，没有连续阈值搜索或复合分数。所有排列使用同一门控：

- 候选必须是正确输入指纹/ID顺序的prediction，status=success，全部相机可用。
- 诊断必须匹配该prediction的字节SHA，状态为evidence_available或partial_evidence，至少一对有几何证据。
- 实际执行时，候选产物缺失或SHA不符亦不可用。不能把部分注册的相机与另一方法补齐。
- partial_evidence可以被优先级选中，但必须带“不是全场景正确性保证”的警示；不给高可靠标签。
- 按优先级选第一个合格候选；首选失败时回退。全部不合格则abstain，统一结果为no_reconstruction、空相机及明确原因。

目标为开发集四实例平均joint AUC@10最大，定义沿用stage3：每对error=max(旋转、有向平移方向)，AUC为平均max(0,1-error/10)，缺失对贡献0。先实例内后实例间等权。开发集允许读取GT以确定优先级；拟合进程禁止打开scan6/test路径及混合evaluation/results文件，避免先读全表再过滤。输入锁只含文件摘要/划分信息，不含GT数值。训练文件访问列表和六个候选全部结果写fit_report。

平局按预声明规范顺序colmap、vggt_ba、vggt_raw的字典序打破，**不是依据测试误差或事后成本挑选**。不把规范顺序伪称学出的最优回退；开发集若没有自然首选失败，后续次序不可由这四例识别。

拟合结果已固定：`vggt_raw → colmap → vggt_ba`，对应`configs/selection/stage5_v1.json`。两个raw首选排列在开发集打平；所有真实开发实例都选raw，次序由上述规范规则决定。policy文件不携带GT误差值、场景条件分支或“模糊”等标签判定逻辑。提交policy后才运行固定测试集的选择。

## 信息隔离与验证

选择输入单独打包：manifest元数据、三份原预测、阶段4无GT诊断和原方法产物的只读硬链接。没有图像推理、标定、reference或评价。选择进程具有GT/评价文件拒读钩子，只按可用性与优先级作决定；决策保留逐候选拒绝原因。导出整套原方法相机与世界单位，不做Sim(3)对齐；产物内容/摘要不变，仅重定位路径。

自然验证8例，真实失败不删除。独立评价脚本在选择结束后才读取GT，使用stage3注册覆盖、joint AUC@5/10/20、旋转/方向角、评价专用Sim(3) ATE。比较三个原始baseline；按dev/test分开汇总，不用小样本作显著性/泛化结论。若等于always-raw，如实报告没有精度收益，不强行包装成可靠性提升。

回退若未自然触发，则另做**仅开发集**故障注入：四开发实例分别屏蔽raw、屏蔽raw+colmap；另在reduced3屏蔽全部候选或令证据全部unknown，共10个探针。模拟输入只在内存副本中改变，原始失败/预测不变。不能把模拟成功算成真实8例的成功，也须披露回退到模糊COLMAP可能很差。另做一次开发输入副本加入无效GT文件的数值不变性验证。

## 成本与资源

本版本是已有快照的**eager**选择，不是按需懒运行模型的调度器。成本必须计入全部3个原始baseline分支（包括OOM/no model）、共享阶段4诊断以及新增选择/产物校验导出。提供历史分段墙钟相加的回放估算，不能称为新测的端到端模型墙钟，也不能只报几毫秒决策称其优于单跑raw。准备/审计和外层输入锁验证未统一计时，另行披露。

沿用原CPU/GPU版本与显存记录。新增策略为CPU元数据/摘要处理，无新模型、无CUDA调用；GPU授权范围仍12GB。本轮不重跑既有OOM，物理峰值记录不能当成重测值。每选择进程180秒预算；输出不覆盖。

验收包括单元/原有回归、实际8例原相机/点云字节不变、未知/部分证据、两级回退、全失败弃权、过期诊断/损坏产物拒绝、开发拟合的测试文件拒读、GT隔离探针及成本核对。完成后推送并停止，不进入点过滤、加权融合或联合优化。
