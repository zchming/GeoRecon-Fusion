# 留出观测识别安全修正：502点最小验证

**结论：没有获得足以继续构建安全修正选择器、扩大融合或调权重的证据。** 生成与验证流程通过，但原门限下只有240/502位置可评分；没有一个源视图层同时满足预声明的正负类数量要求。scan1总体排序明显受源视图影响，源004内部所选子集仍平均有害。结论是此条件下证据不足，不是证明所有留出观测或融合都无效。

## 授权范围与冻结

只复用阶段5原有502个修正位置及既有COLMAP/VGGT预测、轨迹和参考文件。没有修改生产融合规则、alpha、门限、对应集合或原prediction/点云；没有下载数据、训练模型、重跑SfM/官方BA/网络或进入下一阶段。上一轮oracle及原502点结果保持原样。

输入与协议在构造副本前锁定；生成源码哈希随本次不可覆盖的输出归档。评价与报告实现以交付哈希归档，没有按GT分数调参数或选择新的阈值。scan1/scan6都已反复查看，本次为回顾性诊断而非盲测。

复用的是阶段5已有预测内参/外参，不使用阶段6已知K教学模型替换它们，也不引入GT内参。COLMAP原生观测减0.5后使用common像素及K_common=A K_export；经原变换转为VGGT原生518×392像素评分。

## 构造与留出如何分离

每个原源位置、每个有观测的非源图像形成一折。同一地标/同一图像的重复行整组留出，源图像始终保留。构造集至少有两个不同视图；用其全部行进行归一化多视图DLT，保持既有预测相机和内参。验证图像相机同时从两套相机的Sim3拟合中排除，其深度也不进入raw支持计数。

原融合公式保持：alpha=.5，L与重投影均值来自构造行；raw支持仅来自非源、非验证视图。N仍是实际输入5图，因此原N、N−1分母不改。原L≥3行及误差/源投影/3D分歧门限不放宽，重复观测仍按原行数进入L，但不拆分进两边。副本DLT必须有限且构造深度为正。

副本会改变候选坐标与构造统计量，**它不是原502个冻结修正的复现替代品**。所有副本另存，不生成部署prediction.json。对照同时保存相同DLT/门限/公式的完整轨迹候选，以及原冻结加权点，在同一个验证观测上评分；这些是拟合内对照，不能称为留出。

评分为验证图像中raw平均L2重投影误差减副本误差；重复验证行先作为一组平均。两者都要求正深度、有限且位于图像内；这只是投影可用性，不是准确遮挡/可见性证明。每个位置再对有效折的分数、GT距离和收益分别等权平均，不平均三维坐标，不把折视为独立样本。

生成进程使用GT/evaluation读取拒绝钩子并保存访问记录，真值只由独立评价进程在候选落盘后使用。审计护栏不是OS安全沙箱。

## 3. 完整轨迹对照与参考敏感性

完整轨迹DLT副本和原冻结点在同一验证观测评分，均明确标作resubstitution。对于scan1/004，在同一49位置上用这些拟合内分数排序预测交叉拟合收益，AUROC约0.428；真正留出分数为0.536。各对照自身候选收益在该层是单一类别，无法有效比较其分类能力，不能宣称“留出显著优于拟合内”。完整分数、候选及分母均保留。

GT主评价沿用原raw相机→GT Sim3与20万等距STL顶点，对可评分折逐个求距离再按源位置平均；全量本地STL仅作密度敏感性，不重配准。scan1有2个源位置的平均收益正负标签随参考密度变化，scan6为0。源004前25%/50%在全参考下仍平均恶化约0.410/0.599mm，不能靠参考密度翻成正结论。没有重算完整输出F1或声称点云完整度提升。

**本轮不支持在这两个旧物体上继续调权重、拟合安全选择器或扩大传播。** 操作性继续门槛未通过，且主要不足是原门限下有限覆盖、视图内类别缺失与源视图混杂；不是仅仅缺一个更复杂分类器。此前有限候选oracle的局部改善空间仍然成立，本次没有证明所有融合无用。
