# 累计贡献与证据边界

截至阶段6教学版SfM阶段验收，系统已经完成“基线—诊断—选择—过滤—融合—联合优化”的最小实验链，并补充了已知K的双视图教学链。当前贡献以工程协议和可审计的经验结果为主，不能直接等同于新算法或性能突破。阶段5工程与证据验收通过，稳定收益未证实；现有147项不同测试分环境交叉覆盖。阶段6完成双视图、PnP、增量注册与最小固定K BA的教学范围验收，尚未进入阶段7。

当前可支持的表述：**我们建立了一个可审计、运行时不读取真值的多视图重建比较与可靠性策略实验系统，并在固定小样本中验证了多种简单策略的失败边界。**

当前不能支持的表述：已经提出普遍优于VGGT的融合算法、得到校准可靠性概率、达到SOTA、充分证明泛化，或将官方VGGT/COLMAP/BA与现成优化器记为原创。

后续每次项目结果汇报应附简短累计贡献总结，并更新可支持与尚未证实的结论。扩展实验与新阶段仍须用户明确授权。

阶段5新增诊断支持进一步限定结论：保留unknown明显缓解过滤损失；raw跨视图支持权重的开发优势不迁移到测试；固定相机点优化与联合优化差异很小。这些控制在执行前锁定，没有基于测试结果改选默认策略。[验收与局限](stage5_acceptance/report.md)保留逐场景和失败记录。

阶段6补充了已知K的可解释双视图SfM教学链：SIFT匹配、E/RANSAC、四组R/t假设、显式DLT与正深度/视差/重投影过滤，保存并复算中间产物；3个真实图像对中2个接受，8个合成/退化控制符合预期。这是经典算法的教学实现与验证，不是新SfM算法，当时未完成PnP、增量注册或BA；K标定作为明确输入，不能与自估内参Baseline作同条件排名。详见[阶段6报告](stage6/report.md)。

阶段6的PnP子步骤新增唯一2D–3D轨迹关联、EPnP/RANSAC、固定顺序增量注册及新增点三角化。普通3图/5图和模糊5图全部注册，宽间隔种子失败保留；空白新视图PnP失败时原双视图404点保持不变。5组逐数组复算及126项测试交叉覆盖，该子步骤运行仅用CPU，已有位姿和点不优化，当时未接入教学BA；单物体小样本及已知K条件不支持泛化或SOTA主张，新增点数不等于精度提高。见[本轮报告](stage6_incremental/report.md)。

阶段6的BA子步骤补齐固定K、固定首相机和单一尺度坐标的稀疏教学BA，不删点、不改观测或注册集合。三组已有地图的重投影RMSE和平均相对位姿误差均下降；普通五图预算耗尽未收敛，普通/模糊五图尾部观测误差增加，固定原对齐框架的ATE亦退化。保留初始化失败、双视图跳过及共线/零基线/断图/超时控制，134项测试分环境交叉覆盖。这是经典算法实现与单物体小样本证据，不是新BA算法、稳定点云质量收益或泛化证明；阶段5稳定融合收益仍未建立。详见[本轮BA报告](stage6_ba/report.md)。

阶段6验收完成：核对21条原始运行、4组额外BA失败控制，以及历史源码/输入/产物哈希，复算双视图与增量流程并独立检查BA约束和残差；134项不同测试在两环境交叉覆盖，其中24项属于教学几何模块。验收期间未修改算法、配置、数据或历史结果，汇总了重复失败的计数边界、BA预算耗尽与局部退化。当前可以支持“小型已知K教学SfM全链路实现与验证”，不能支持生产级完整度、未知场景泛化或点云真值质量改善。停止于阶段6，见[阶段验收报告](stage6_acceptance/report.md)。

受限回顾性诊断新增：对阶段5既有502点锁定有限候选oracle、端点互补与伤害来源控制，复现源视图异质性、参考密度敏感性和重复观测来源；没有重新训练、选择权重或修改规则。发现局部插值有oracle空间，但经典端点多数更差，单变量信号缺乏跨场景一致证据，scan6负例仅1个使AUROC不稳定。因此不支持扩大当前启发式融合，也未证明任何融合不可能有效。140项测试分环境交叉覆盖；这是诊断证据而非新融合算法，见[502点诊断报告](fusion_diagnostics_502/report.md)。

观测级留出最小验证：固定原502个位置，对非源图像整组留出，重建诊断副本并排除验证相机/深度参与对齐和支持统计。保留1447折的全部构造拒绝与262个无有效折位置；240个可评位置没有提供足够的源视图内正负类证据，scan1总体AUROC由源视图差异显著解释，高分子集并未成为安全修正。147项测试交叉覆盖、逐折与参考密度复算通过。新增贡献为可复现的条件交叉拟合和源视图混杂检验，不是新融合算法或严格独立验证；原规则、产物与阶段边界未变。详见[留出诊断报告](heldout_fusion_502/report.md)。

SIFT＋LightGlue预检新增只读历史匹配图审计、RootSIFT/尺度/方向输入契约及官方权重参数完整性检查。两组现有DTU图像在本地GPU完成接口烟测，显存远低于12GB；旧坐标逐点一致，保留首次配置序列化失败。当前贡献是候选前端的可复现兼容性证据，尚未实施后端接入或证明精度/鲁棒性提升。提取器默认差异、描述子度量变化与坐标上游TODO均已记录，见[预检报告](sift_lightglue_preflight/report.md)。
