# Stage 7A 固定划分留出几何诊断

**判断：当前留出指标有信息，但不足以支持安全替换；不继续将本版指标开发成替换策略。** 9 个可比较的“留出后 C 纠正 B”对中主指标偏向 C 8 个；4 个“留出后 C 伤害 B”对中仍有 2 个错误偏向 C。预先声明的网格均衡辅指标也未解决伤害。原 Stage 7A **NO_GO_EVIDENCE 不变**，本轮不实现策略、不进入 Stage 7B、不提交或推送。

## 范围与固定设计

用户已明确批准真正的留出几何诊断。[新诊断配置](../configs/experiments/stage7a_heldout_geometry_v1.json)在运行前写定；不改旧协议、划分、阈值或原教学几何后端。[前一步可行性检查](stage7a_holdout_feasibility.md)保留原样。

- 使用原 46 个去重对、同一 DTU 公共输入和已知 K，只复用 SIFT/RootSIFT/LightGlue 缓存。保持上一步 1 px 连通分组及 SHA256 25% 分量留出，逐分量核对哈希；不重抽、不调盐、不按焦点标签重分配。
- B/C 拟合分别使用各自属于拟合分量的**全部原始匹配**，原序号排序；没有在拟合侧去重、筛点、改权重或改求解器。共同分组端点不跨入验证侧。
- 验证每条分组边使用原 B/C 并集中字典序最小的实际观测对，不生成或平均坐标；同一实际像素、同一 B/C 来源成员关系用于两个候选。别名代表的固定选择仍是局限，分组不证明同一 3D 点。缓存匹配生成时已使用整图特征；此次只对几何拟合留出，不是独立匹配源、空间块不相交或未见物体验证。
- 原 `reconstruct()` 与 Stage6 配置保持字节相同，只替换三个预设种子 42/43/44。原 4 个结构不可评估对两组均跳过，不补值；其他拟合失败完整保留，不用旧全量位姿或被拒绝候选替代。
- 推理/求解工作进程只读取准备好的拟合/验证 NPZ、已知 K 和固定参数；禁止读取原结果/真值、模型权重、Torch 或网络。全部结果落盘、进程退出后才用独立 `evaluate` 命令读取真值并附加旧焦点标签。没有新特征、匹配、模型推理、BA 或下载。

主诊断是 **截断 sqrt-Sampson 损失**：每观测 `min(error/1.5px,1)`，对 B 来源验证边求均值、对 C 来源求均值，再各权重 1/2。共有边只存一行，权重为两来源贡献之和，不作为重复独立观测；两候选使用同一权重和数据。非有限误差固定计损失 1，并单报数量。容差 1e-12 仅判 B较低/C较低/相同/未知，**没有采用该排序输出位姿，也没有定义可学习的接受阈值**。

辅诊断预先固定为：同样损失的共有/B独有/C独有分层；按来源及原 8×6 观察网格均衡的损失；验证点的双正深度及旧视差/重投影条件支持。空层为未知，不重加权成“该层已通过”。验证三角化只检查固定姿态，不反向修改姿态。

原 4 对仍为 `scan1_spaced_001_020`、`scan1_spaced_010_020`、`scan6_spaced_001_020`、`scan6_spaced_010_020`；原约 63° 新错误接受案例属于最后一对，仍不能评估。

## 决策、成本与检查

按前一步止损边界，本版留出指标**尚不能安全区分收益与伤害**。不继续把它实现为替换策略，不通过调 cap、换盐、只保留有利来源层或新增例外来修饰结果。保留本诊断入口用于今后独立改进的验收；其他信号或算法方向需要新证据和单独授权，本轮不自动转向或进入 Stage 7B。此结论只限制当前固定数据、固定划分、固定信号，并非证明一切留出方法无效。

- 准备＋受监督求解会话 **3.105 s**，工作进程峰值 RSS **69.98 MiB**；CPU 8 线程，OpenCL关闭，无 Torch/CUDA/模型或 GPU 分配，不触及 12GB GPU 预算。每组180s、总1800s、单进程8GiB及产物1GiB约束均未触限。
- 新增 **9 项测试全通过**：真实观测代表选择、B/C交换不变性、保留拟合别名、端点泄漏拒绝、固定排序、来源权重、平移符号/正深度、读取保护及新进程合成求解。
- 当前实验环境完整回归 **188 项：187 通过、1 跳过、0 失败/错误**。跳过为缺 PyCOLMAP 的原生空场景测试。原临时 CPU CI 环境已不存在，此次没有重新安装依赖或冒称 CPU CI 通过；未推送，远程 CI 未触发。
- 独立只读复核实际拟合索引、所有固定分量、验证原像素与来源成员关系、端点隔离、全部损失/深度及支持掩码；不再拟合或三角化，与输出一致。验证后不改变 R/t，所有接受姿态与原后端数组逐项保留。
- 本轮没有修改任何原有跟踪文件或上一轮 6 个待审文件；旧 Stage 7A、可行性检查缓存及首轮失败证据保留并逐文件核对哈希。
