## 几何支持与恢复案例

每物体 13 个困难对上的统计如下。GT一致仅表示 **真值极线 sqrt-Sampson≤1.5 px 的代理**，没有测真实 3D 对应精度；网格覆盖也没有对象/可见性掩码。配对差中位数不等于两个中位数之差。

| 物体 | GT一致数中位数 B→C | GT一致数配对差中位数 | 网格覆盖配对差中位数 | 极线兼容率中位数 B→C |
|---|---:|---:|---:|---:|
| scan1 | 87→157 | +66 | +0.1250 | 91.00%→84.41% |
| scan6 | 71→176 | +101 | +0.1875 | 91.03%→81.86% |

7 个 G1 恢复对均由 B 的 **0/3 正确变为 C 的 3/3 正确**，全部发生于 blur5：scan1 的 002–005、003–005；scan6 的 001–002、001–003、002–004、002–005、003–005。B 在这些对原本有输出但位姿错误，不能表述成救回 7 个无输出场景。

两物体的 spaced3 正确率 B/C 都仍为 1/3，尚未提高宽间隔正确初始化率。scan1 001–020 的 A/B/C 候选数 4/5/28，GT一致数 1/3/1；C 只有 10 个 E 内点，被原门限拒绝，预检的“28 条候选”没有转化成正确重建。

## 保留的伤害与失败

新增错误接受为 **6 个不同图像对、18 个 pair-seed 事件**，三个种子一致；其中两个普通对 `scan1_sharp_003_005`、`scan6_sharp_001_004` 原 B 为 3/3 正确、C 为 0/3 正确。下表列全部新增错误接受，而非只挑代表反例。

| 图像对 | B 联合角误差 | C 联合角误差 | GT一致候选数 B→C |
|---|---:|---:|---:|
| scan1_sharp_003_005 | 4.689° | 5.773° | 272→989 |
| scan1_blur_001_004 | 4.934° | 8.525° | 47→105 |
| scan1_blur_001_005 | 3.648° | 9.206° | 27→56 |
| scan6_sharp_001_004 | 4.124° | 6.548° | 230→580 |
| scan6_spaced_010_020 | 拒绝，无位姿 | 63.367° | 2→2 |
| scan6_blur_001_004 | 4.927° | 16.316° | 52→116 |

尽管总错误接受从 B 的 13 对降至 C 的 10 对，新增伤害仍违反冻结 G2。尤其 scan6 spaced 010–020：C 的 104 个候选中只有 2 个 GT 极线兼容，却通过 E 52 内点、51 个接受点、双正深度率 1.0、最大重投影 1.007 px，输出约 63.37° 联合误差。该反例直接说明原几何接受条件可以接受错误共识；尚未进一步验证具体纹理或场景成因。没有据此改阈值、过滤匹配或加入新后端。

逐种子拒绝原因：A 有 4 对匹配不足、2 对单应占优、2 对视差/重投影支持不足；B 有 4 对匹配不足、2 对单应占优；C 有 3 对 E 内点不足。拒绝的候选位姿、掩码、深度和三角化中间结果均保留，不用 GT 从失败候选中挑解。

## 实现、复现与累计贡献

入口 [run_stage7a.py](../scripts/run_stage7a.py)；[特征](../src/georecon/matching/features.py)、[执行编排](../src/georecon/matching/session.py)、[隔离进程](../src/georecon/matching/worker.py)、[离线评价](../src/georecon/matching/evaluate.py)、[指标及冻结门](../src/georecon/matching/metrics.py)。需现有 DTU 公共输入缓存及协议锁定的 Python/包版本、LightGlue vendor 和缓存权重；不自动下载，只 clone 仓库无法完整复现。批准新的复跑时使用新目录：

```bash
PYTHONPATH=src python scripts/run_stage7a.py run \
  --output outputs/stage7a_v1_new_run \
  --official-repo /path/to/frozen/LightGlue \
  --checkpoint /path/to/cached/sift_lightglue_v0-1_arxiv.pth
PYTHONPATH=src python scripts/run_stage7a.py evaluate \
  --output outputs/stage7a_v1_new_run
python -m unittest discover -s tests -v
```

`evaluate --review-output <新目录>` 只做离线复核并保留旧评价。原 CLI、教学流程和历史复现路径未改，冻结协议/后端/配置未变。

累计已实现统一几何与数据协议、COLMAP/VGGT 适配、已知 K 教学 SfM/PnP/增量/BA、可靠性/融合消融及失败诊断；本轮新增受控三组前端执行、独立真值评价、预算测量与可证伪决策，实际发现“更多几何支持和更高平均 AUC 仍可带来新错误接受”的具体反例。LightGlue 模型/权重、OpenCV 求解器与经典 SfM 算法属于第三方/既有方法，本项目不认领原创算法贡献。两个已反复查看的 DTU 物体、已知内参、相关条件、相同种子输出及极线代理限制，均不足以支持未知场景泛化、稠密点云质量提升或稳定无伤害优化。
