# 阶段4 v1：几何可靠性诊断的预先约定

沿用阶段3不可更改的数据划分与8个实例：scan1/dev、scan6/test，各normal5、reduced3、spaced3、blur5。阶段3freeze SHA为`2a5e898c2e3807bacd22d056b172e782d4794babb0121dfdb5da2a8da9426df0`。基线预测不重跑、不修改，24个结果中的6个失败全部保留。阶段3已看过测试结果，因此此轮是同一固定数据上的回顾性诊断验证，不能声称是一个从未接触的独立测试集。

阶段3先核对每个预测与已发布副本一致、各产物SHA及重新计算的GT评价完全一致，记录`stage3_audit.json`。其后准备独立输入bundle，锁定文件摘要`input_lock.json`。bundle只含原清单和图像、三份预测JSON及raw预测NPZ，不含GT相机、标定、reference或evaluation。可靠性推理进程只得到bundle、固定config和输出路径，另装Python文件访问审计钩子拒绝GT/评价文件。该钩子是数据流防误读检查，不声称是抵抗恶意代码的完整安全沙箱。评价在另一脚本、推理结束后执行。

## 少量可解释信号

1. **独立提取的图像匹配对预测相机的支持。** 共同800×600输入上OpenCV SIFT4096，双向L2 KNN互相匹配与Lowe ratio 0.75；不读取COLMAP数据库、BA轨迹、模型confidence或预测几何来提取/筛选这些观测。按匹配索引交替划分：一半仅拟合图像F（RANSAC1.5px，10000次，confidence0.999），另一半审计，最多512个等间距索引样本。图像F的审计支持只作为观测质量上下文，不据它筛掉被测预测的不利匹配。匹配与既有baseline的SIFT/跟踪点可能空间重叠，不声称是统计独立的真实留出图像或观测。
2. **相机几何残差与正深度。** 用预测的原图K/R/t按共同预处理像素中心变换回800×600，计算`F=K2^-T [t21]x R21 K1^-1`。输出匹配级sqrt Sampson距离（px），视图对中位/P90、1.5px以内比例。该残差来自实际图像对应，不是自身深度生成点再回投自身。对同一批观测做预测相机条件下的DLT，报告双正深度占全部审计匹配的比例、有限点数和夹角中位数；这是几何可行性，非独立3D准确率。Sampson不能分辨t与−t，正深度是额外诊断，不合成为选择规则。
3. **跨视图深度一致性，限VGGT raw。** 在原生深度网格按stride16取固定样本，用源视图Z-depth及其相机反投影，再投到不同目标视图，与目标自身预测深度双线性比较：`abs(z_projected-d_target)/max(z_projected,d_target)`。报告正深度/双线性采样合法覆盖、误差中位与0.05以内比例。至少64个有效样本。没有用置信度过滤，也未进行遮挡或padding清除；同一联合模型输出有相关性，低差异只说明内部一致，不能当成独立正确性证据。BA仅有优化后稀疏点，不能拿它的初始化深度冒充优化后深度；COLMAP SfM同理标为not_supported。

raw confidence只作原始数值分布上下文，不归一化成概率。没有GT校准、通用总分或跨方法可靠性排序。不会新增模型、修改基线、做点过滤、改相机、方法选择、回退、加权或融合。

## 证据不足与层级

每对至少24个审计匹配，且两图各覆盖8×6网格的至少4格，否则unknown。缺失相机、失败/OOM基线、零基线或未定义极线也保留unknown及原因，数值为null，不给“高可靠”。输入匹配图的连通分量与孤立视图单独报告，不用它替代缺失方法输出。

层级明确区分：保存匹配级残差NPZ；视图对统计；按相邻有效对聚合的视图统计；场景级有效对数量/比例和“有效对中位数的中位数”。部分证据的场景统计必须附覆盖率。不声称实现了完整多视图轨迹或轨迹长度信号，也不把稀疏匹配级输出称为稠密逐像素正确率。

## 验证与资源

所有阈值在诊断计算前固定于`configs/reliability/stage4_v1.json`。阈值是几何容差或最少证据要求，不是由测试GT选择的准确率门槛。开发集仅分析信号与真实误差关系，不拟合阈值、概率或复合权重。测试同样只在信号已生成后由独立评价脚本读取GT；本轮不根据相关系数修改配置重跑。

评价器重新计算相对位姿误差，主要目标为各实例所有已评价相机对的`max(rotation,oriented translation)`均值；另保留ATE和阶段3失败类型。每方法、每划分分别报告信号—误差的Spearman描述相关，至少3个可用实例且变量非恒定；不混池跨方法分数。每划分只有一个场景、四种相关条件，小样本相关不做显著性/泛化结论；BA可用仅2例/划分时明确不可计算。不把无输出/OOM、无匹配的实例当0误差或0残差，全部列入状态与证据覆盖表。

复用本地预测，新增图像匹配与向量化几何使用8线程CPU；没有需要重新调用GPU的大模型计算，不产生新增CUDA分配。本机GPU授权上限仍为12GB，未扩大该限制。每实例诊断进程180秒预算。报告共享匹配开销、每分支诊断开销、进程总墙钟和OS RSS；旧基线成本另列，不能声称可靠性免费或已降低端到端成本。

数学/数据流检查覆盖：错误观测、对极平移符号歧义与正深度、Sim(3)规范不变性、零基线、跨视图目标深度改变、边界采样、空匹配、无输出不造分数、重复性、真实GT文件打开被拒绝。完整验收后推送并停止于阶段4。

实现依据：[OpenCV匹配接口](https://docs.opencv.org/4.x/d1/de0/tutorial_py_feature_homography.html)、[相机/极几何接口与约定](https://docs.opencv.org/4.x/d9/d0c/group__calib3d.html)。本机实际OpenCV为5.0.0（发行包5.0.0.93），API及行为由测试验证；这些通用几何量不包装成原创算法。
