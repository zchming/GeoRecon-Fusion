# 502个原融合修正点：互补性、伤害来源与可识别性诊断

**结论：当前不建议继续扩大或调参已有启发式加权融合。** 两个物体均存在明显的“有限候选插值oracle”局部改善空间，但经典端点通常更差，且预先声明的单变量信号没有通过跨场景一致可识别性门。可以保留一个后续研究假设，不能据此推出融合不可能有效，也不能宣布新方法或稳定收益。

诊断协议、oracle动作、12个信号及固定方向、参考密度敏感性与探索性继续门槛在首轮计算前以文件哈希锁定。两场景都已被前序实验查看，scan6不再是盲测；不选新权重、不按结果反转信号方向。旧阶段5全部输入/源码/规则/产物哈希核对，旧8条件融合检查器以只读方式通过。

主距离保持原始raw预测相机→GT Sim3与20万个等距STL顶点，以全部受影响点到参考表面的最近邻距离评价，不套ROI、不重配准。它没有真实逐点对应标签，不是官方完整DTU评价。固定原raw ObsMask子集与全量现有STL顶点分别单列，不替换主结论。所有GT都只在本次后验诊断使用，不能进入推理或部署。

## 1. 互补性：端点很差，但少量插值可能有用

|物体|点数/不同经典地标|raw均距 mm|原加权均距 mm|经典端点均距 mm|oracle均距 mm|原加权改善/恶化|
|---|---:|---:|---:|---:|---:|---|
|dtu_scan1_normal5|174/174|2.896|2.225|22.014|1.303|90/84|
|dtu_scan6_normal5|328/328|7.002|3.630|14.109|1.270|327/1|

oracle逐点选择beta∈{0,0.25,0.5,0.75,1}或该点原冻结加权beta，最小化同一参考最近邻距离；平分先选raw。原raw与原加权动作都在集合内，所以oracle必不比这两者差。它是有限动作集合中的真值后验最好结果，不是连续最优、完整点云F1上界、召回收益或可部署方法。

scan1：经典端点仅5/174点优于raw；scan6仅4/328点。预先要求“两物体端点优于raw比例≥20%”的门不通过。另一方面，有限动作oracle相对raw的均距降低约55.0%/81.9%，说明端点更差与插值有用可以同时成立。因此不能把未通过端点门解释为完全没有可利用的融合信息。该门是探索性投入决策，不是统计检验或普遍必要条件。

不能把看到scan6的beta=0.25均距较低就改规则：它在同一旧样本上的结果只作诊断。现有加权输出和默认禁用状态均未改变。

scan1负点头置信度的总体AUROC为0.874，但在003内降至0.030，在004内约0.543，提示强烈的源视图混杂。最小视差在scan1分层内仍有信息，但scan6总体未支持同向关系；scan6只有一个负例，不能据其AUROC宣布该信号无效或可迁移。轨迹重投影使用COLMAP已拟合过的观测，不是独立/留出验证证据；预测深度支持同样可能共享误差。

## 5. 失败保留与输入问题

scan6有2个修正位置的源图像出现重复观测；4个修正地标的轨迹观测数高于独立视图数。旧权重使用观测长度，因此不能解释为独立视图证据数；这不等于已证明这4点导致主要伤害，本次没有重算或部署去重权重。旧规则本来接受这些观测；本次精确重放关联并核对源行，未将诊断脚本的失败算作新的SfM失败。

## 是否值得继续，以及累计贡献

**不建议继续给现有权重增加复杂度、放宽门限或扩大传播。** 证据说明有限候选的局部插值有改善空间，但端点优势、可识别信号和有效覆盖尚不足，无法支撑稳定整体融合收益。值得保留的研究问题是：能否用不共享当前拟合偏差的验证观测，在不同物体/视图内识别安全修正；若以后单独授权，只应先做这个可证伪的小验证，而非立即训练新模型或宣称创新。

累计工程贡献仍是统一基线/坐标/失败协议、可靠性与选择/融合/优化实验，以及已验收的教学SfM链。本次增加了锁定候选的oracle诊断、完整伤害与源视图分层、参考密度敏感性和观测重复的审计证据。贡献是可复现的诊断和经验边界，不是新的融合算法。

局限：两个已反复查看的物体、只覆盖合格锚点的502个条件位置、最近表面距离无真实对应、GT相机辅助与双线性控制不能唯一归因、极端类别不平衡、单变量未校准、没有独立盲测或整体F1收益验证。不修改原规则、不下载数据，也未进入下一阶段。
